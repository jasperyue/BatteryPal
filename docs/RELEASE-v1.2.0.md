## Changes / 更新

- Redesigned the pineapple menu bar theme with rounded fruit, a short leaf crown, and clear low, normal, high, and charging expressions.
- Charging uses an external pulsing lightning bolt and a brief blink every six seconds.
- Split theme renderers from battery state and menu bar handling for easier theme development.
- Added a one-command GitHub Release and Homebrew tap publishing script.

- 重新设计菠萝菜单栏主题：圆润果身、短叶冠，以及低电量、普通、高电量和充电表情。
- 充电时右侧闪电亮暗交替，每 6 秒短暂眨眼。
- 拆分主题渲染器、电池状态和菜单栏逻辑，方便扩展主题。
- 新增一键发布 GitHub Release 和 Homebrew tap 脚本。

Requires Apple Silicon and macOS 13+. Quit Battery Pie before upgrading.
需要 Apple Silicon 和 macOS 13 或更新版本，升级前请退出 Battery Pie。

The app is ad-hoc signed and not notarized by Apple. If macOS blocks first launch and you trust the source, use System Settings → Privacy & Security → Open Anyway.
应用使用本地签名，未经过 Apple 公证。首次启动若被拦截，确认来源后可在系统设置 → 隐私与安全性中选择「仍要打开」。
