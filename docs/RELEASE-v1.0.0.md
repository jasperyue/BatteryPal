首个公开版本，适用于 Apple Silicon Mac，要求 macOS 13 或更新版本。

- Low / Normal / High / Charging 四种原创电池表情。
- 28×18 点菜单栏图标，适配明暗外观。
- 实时电量和供电状态、百分比开关、可选登录启动。
- 充电时低频闪电和眨眼动画；休眠、停止充电或开启“减少动态效果”时停止。
- 无网络请求、无遥测、无第三方运行时依赖。

下载 `BatteryPal-1.0.0-arm64.dmg`，打开后将 App 拖入 Applications。
本版本采用 ad-hoc 本地签名，未提交 Apple 公证。首次启动如被拦截，在确认来源可信后，可前往「系统设置 → 隐私与安全性 → 仍要打开」。无需关闭全局安全检查。

提供 SHA-256 校验文件。Intel Mac 用户可从源码自行编译；本次发布的二进制仅支持 Apple Silicon。
